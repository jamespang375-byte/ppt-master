# 豆包风格 Brand Spec

> 来源：Surge Huawei AI Broadband V24.pptx + 贵州安顺Openclaw提示词工程实战培训.pptx 综合提取
> 以后用户说"豆包风格"即指本文件的设计语言。

## 整体风格定位

**浅色系 + 华为红主调** — 像华为对外发布的正式PPT，不是深色科技风。
- 背景：白色，不用深蓝色封面
- 主色：华为红 #C00000 贯穿标题、线条、强调
- 封面：白色背景 + 红色标题 + 红/金圆形装饰 + KPI数据卡片
- 内页：白色背景 + 三色协奏卡片（红/金/蓝彩条）
- 收尾：深蓝渐变（唯一用深色的页面）

## 布局规则

### 封面模式（纯白色，禁止任何图片）
1. **纯白色背景** — 不用深蓝渐变，不用AI生图叠加，不用任何图片
2. 顶部红色细线（横贯全宽，4px高）
3. 底部红色细线（同上）
4. 左侧红色竖条（全高，8px宽）
5. 右上角红色大圆装饰（#C00000, opacity 0.08）
6. 右上角浅红中圆装饰（#E84545, opacity 0.12）
7. 左下角金色大圆装饰（#D4A843, opacity 0.1）
8. 标题区：红色大标题(50px bold) + 深灰副标题(27px) + 灰色说明(15px)
9. 下方4个KPI数字卡片（不同Tint底色+彩条，每个含数字+单位+说明+来源）
10. 底部信息行：报告类型 | 日期 | 页码（灰色小字）
11. 右下角华为Logo（可选，opacity 0.6）

### 内容页布局变化规则（HARD — 禁止每页都用同一模板）

> 参考PPT每页有65-100个文本块，6-10个信息区。当前问题是每页都是"标题→三列卡片→底部条"的重复。
> **每页必须选择不同的布局模式**，禁止连续两页使用相同布局。

#### 布局模式库（每页至少选一种，可组合）

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **A. KPI仪表盘** | 顶部4-6个大数字卡片(2行×3列)，下方详细说明区 | 数据速览、核心指标 |
| **B. 左右对比** | 左右各一个主题区，内部有标题+数据+说明+来源 | 优劣对比、正反分析 |
| **C. 流程链** | 3-5个步骤横向排列，箭头连接，每步有编号+标题+说明 | 发展阶段、实施路径 |
| **D. 矩阵网格** | 2×2或2×3网格，每格独立主题卡片 | 风险评估、多维分析 |
| **E. 时间轴** | 水平/垂直时间轴，节点+事件+数据 | 历程、里程碑、规划 |
| **F. 左文右图** | 左侧2/3文字内容（多栏卡片），右侧1/3图片+说明 | 产业介绍、案例展示 |
| **G. 上图下数据** | 上方1/3图片，下方2/3数据卡片区 | 场景展示+数据支撑 |
| **H. 层级架构** | 3-4层水平条带，每层2-4个模块卡 | 技术架构、体系框架 |
| **I. 引用强调** | 页面中心大号引用语+来源，周围数据点 | 核心观点、专家判断 |
| **J. 表格密集** | 全宽数据表格+进度条+颜色编码 | 指标体系、目标对比 |
| **K. 漏斗/金字塔** | 从上到下逐层收窄，每层标题+数据+占比 | 转化漏斗、层级分解 |
| **L. 雷达对比** | 多维能力雷达图+两侧文字解读 | 竞品对比、能力评估 |
| **M. 卡片瀑布** | 3列不等高卡片瀑布排列，每列2-3张高度不同 | 分类展示、信息聚合 |
| **N. 架构蓝图** | 4-5层水平条带，每层3-6个模块卡，层间用箭头连接 | 技术架构、体系框架、平台能力 |
| **O. 多阶段流程** | 2-3个大阶段，每阶段含3-4个子步骤，有分支和可选路径 | 实施方法论、变革路径 |
| **P. 生态拓扑** | 中心节点+辐射连接+外围模块，节点间用线连接 | 产业生态、供应链、合作体系 |
| **Q. 空间模型** | 非线性空间布局（如"一横一纵一圈"），多维度交叉 | 战略框架、模式定义 |
| **R. 引用评注** | 页面主体是引用框+评注，周围有数据支撑 | 专家观点、案例点评、读书笔记 |

#### 信息密度要求（HARD）

| 指标 | 要求 |
|------|------|
| 每页文本块数 | **≥40个**（参考PPT为65-100） |
| 每页形状元素数 | **≥35个** |
| KPI数字页 | 至少4个大数字，每个附带2个对比值+来源 |
| 卡片页 | 每张卡片至少5层信息（标签→数据→解释→对比→来源） |
| 混合布局 | 至少2种布局元素组合（如KPI卡片+流程链+对比行） |

#### 排版变化手法（必须使用至少3种）

| 手法 | 说明 |
|------|------|
| **大小数字对比** | 44px大数字 + 16px说明 + 14px来源，形成3级层次 |
| **标签编号** | 每个区域有英文标签(SCENE 01/CORE METRIC等)+中文标题 |
| **彩色进度条** | 数据用进度条可视化，不用纯文字 |
| **嵌套卡片** | 大卡片内嵌小卡片，形成层次 |
| **侧边数据条** | 页面一侧竖向排列3-5个小数据点 |
| **区域分割线** | 用1px灰线分区，不用大色块 |
| **多级标题** | 区域标题(20px) > 子标题(16px) > 正文(14px) 三级 |
| **图片嵌入** | 内容页用左文右图或上图下数据模式嵌入实景图 |
| **数据标注线** | 从数字引出细线连接说明文字 |
| **色块标签** | 小色块+白字作为分类标签（如红色"风险"金色"价值"） |
| **模块箭头连接** | 卡片/模块间用箭头表示流向和依赖关系 |
| **分层标注** | 架构图层与层之间有标签条+说明文字 |
| **编号系统** | 每个区域/步骤有数字编号(01/02/03)，大号粗体 |
| **引用框** | 独立边框框住引用语，配来源和评注 |
| **表格内嵌图示** | 表格单元格中嵌入小图标或色块，不只纯文字 |
| **双坐标对比** | 左右两侧用不同颜色编码（如红色US/蓝色China） |

#### 底部面板规则（HARD — 简化）

> 底部深色面板只保留Key Insight一行，**禁止**放导航信息（前页/本页/下页）。

**底部面板结构（高度50px，y: 670-720）：**
1. 深色背景 #1A1A1A
2. 左侧金色竖条（6px宽）
3. "Key Insight"标签（金色 #D4A843, 14px）
4. 一句核心洞察（白色, 14px）
5. 右下角页码（灰底白字小方块）
6. **禁止**：导航信息、前页/下页、多余文字

### 章节页模式（浅色版）
1. **白色背景**
2. 顶部红色细线
3. 右上角红色圆装饰（opacity 0.08）
4. 左下角金色圆装饰（opacity 0.1）
5. 巨大数字（50px, 12% opacity, 红色）
6. 8px红色竖条 + 章节标题
7. 下方3个预览卡片（本章内容概览）

### 收尾页模式（唯一深色页）
1. 深蓝渐变背景（#051937→#0A2B6B）
2. AI生图半透明叠加（opacity 0.3）
3. 三组核心数字居中（白色大字）
4. 金色短线 + 标语
5. 底部支撑数据条

## 信息密度规则（HARD — 不可降低）

### 每页文本量下限

| 页面类型 | 最少文本字符数 | 最少形状元素数 |
|---------|-------------|-------------|
| 封面 | 200字 | 15个 |
| 章节分隔页 | 150字 | 8个 |
| 内容页（KPI/数据型） | **800字** | **40个** |
| 内容页（表格型） | 500字 | 30个 |
| 内容页（卡片/对比型） | **700字** | **35个** |

### 每张卡片必须包含的信息层

一张卡片**不允许**只有标题+大数字+1行说明。每张卡片至少包含：

| 层 | 内容 | 示例 |
|----|------|------|
| ① 标签/标题 | 卡片主题 | "人均GDP" |
| ② 核心数据 | 大号粗体数字 | "$14,837" |
| ③ 上下文解释 | 1-2句说明 | "恰处高收入门槛边缘" |
| ④ 对比值或趋势 | 横向参照 | "韩国：$12,000→$35,000" |
| ⑤ 来源标注 | Source行 | "Source: IMF 2025" |

### 每页区域填充规则

- **上半区（y: 40-380）**：主内容区，3-4列并排卡片，每列2-3层堆叠
- **下半区（y: 380-650）**：辅助数据区——对比行、补充KPI、图片、来源标注
- **底部条（y: 650-720）**：深色面板——引言/洞察/Source汇总

## 图片使用规则（HARD — 豆包风格必须配图）

> 当 `.env` 中配置了 `IMAGE_BACKEND`（如 zhipu）和 `PEXELS_API_KEY` 时，Strategist 必须将 `image_usage` 设为 `["ai", "web"]`，不得推荐 `none`。

### 动态配图规则（HARD — 禁止复用旧图）

> **每次生成新PPT时，必须基于该PPT的具体内容动态搜索和生成图片。**
> 禁止复用其他项目的图片文件。每份PPT的图片必须与该PPT的内容主题匹配。

#### 图片获取流程（Strategist §VIII 阶段执行）

1. **Strategist 读取源素材**，识别需要配图的页面（产业/场景页）
2. **为每个需要配图的页面生成搜索关键词**，关键词必须基于该页具体内容
   - 例如：光伏产业页 → 搜索 "solar panel photovoltaic farm"
   - 例如：智慧交通页 → 搜索 "smart traffic city autonomous driving"
   - 例如：芯片竞争页 → 搜索 "AI chip semiconductor manufacturing"
3. **Pexels搜图**：用 `image_search.py` 搜索，`--filename` 必须带 `.jpg` 扩展名
   - 关键词要具体（2-5个词最佳），不要泛泛搜索
   - 每个搜索关键词应该反映该页的核心主题
4. **AI生图**：用 `image_gen.py` 生成封面/收尾背景图
   - prompt 要反映该PPT的具体主题，不要用通用prompt
   - 例如：AI芯片PPT → "Abstract deep navy blue background with golden circuit patterns and chip silhouettes"
   - 例如：新能源PPT → "Abstract green energy background with wind turbines and solar panels, golden hour"
5. **图片保存到该项目的 `images/` 目录**，不跨项目复用

#### 配图规则

| 页面类型 | 图片来源 | 用途 | 嵌入方式 |
|---------|---------|------|---------|
| **封面** | **不配图** | 纯白+装饰圆+KPI卡片 | **禁止任何图片** |
| **收尾** | AI生图（基于该PPT主题） | 深蓝渐变背景+图片叠加 | `<image opacity="0.3">` 全画布 |
| **章节页** | 不配图 | 纯色+巨大数字+圆形装饰 | — |
| **产业/场景页** | Pexels搜图（基于该页内容） | 左文右图 或 上图下数据 | `<image>` 占页面1/3-1/2区域 |
| **数据密集页** | 不配图 | 纯SVG卡片 | — |

#### 图片嵌入方式

1. **内容页配图**：用布局模式F(左文右图)或G(上图下数据)，图片区域加左侧5px彩条
2. **收尾**：图片作为全画布背景，深蓝渐变遮罩

## 华为Logo

- 位置：右下角，距离右边缘和底边缘各 20px
- 尺寸：宽度 80-100px，高度按比例
- 透明度：opacity 0.6-0.8
- 仅在封面和收尾页放置，内容页不放
- 如果没有Logo素材文件，省略

## 禁止清单
- ❌ 封面用深蓝渐变背景（封面必须纯白！）
- ❌ 封面使用任何图片（包括AI生图、搜图）
- ❌ 圆角（任何radius > 0）
- ❌ 阴影（任何drop-shadow/blur/filter）
- ❌ 大面积留白
- ❌ 单色设计（必须三色协奏）
- ❌ 卡片只有标题+数字+1行说明（至少5层信息）
- ❌ 数据点无来源标注
- ❌ 标题用黑色（标题必须用华为红 #C00000）
- ❌ 内容页全部纯文字无图片（当有可用图片时，至少2页嵌入实景图）
- ❌ 连续两页使用相同布局模式
- ❌ 每页文本块少于40个
- ❌ 底部面板放导航信息（前页/本页/下页）— 只保留Key Insight一行
- ❌ 底部面板高度超过50px
